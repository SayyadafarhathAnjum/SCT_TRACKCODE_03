# 🐱🐶 Cat vs Dog Classification using SVM

A Support Vector Machine (SVM) model to classify 
images of cats and dogs from the Kaggle dataset.

## 📌 Task
SkillCraft Technology - Task 03

## 📊 Dataset
[Dog/Cats Dataset - Kaggle](https://www.kaggle.com/datasets/salader/dogs-vs-cats)

## 🔧 Tech Stack
- Python
- Scikit-learn (SVM)
- OpenCV
- NumPy, Matplotlib
- Streamlit (Live App)

## 🚀 How to Run
pip install -r requirements.txt
python svm_classifier.py
